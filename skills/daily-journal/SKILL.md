# 每日日志

把转瞬即逝的东西留下来：心情、读书、灵感。统一写进当天那一页日记。

## 存储结构

```
~/.workbuddy/journal/
└── 2026-09/
    └── 2026-09-16.md
```

一天一个文件，文件内按「心情 / 读书 / 灵感」分节，每条带时间戳：

```markdown
# 2026-09-16 周三

## 心情
21:48 今天把课纲收尾了，心里踏实  #状态

## 读书
21:48 《置身事内》P88：土地财政的本质是地方政府信用  #经济 #摘录

## 灵感
21:48 短视频选题：AI 帮老板省下的不是钱，是决策时间
```

目录按月分，文件按天建，分节按需创建、固定顺序为心情 → 读书 → 灵感。用户没记的类型不生成空节。

## 工作流

1. **判断类型**，三类：`mood` 心情、`reading` 读书、`idea` 灵感。
   - 情绪、状态、感受、吐槽、复盘 → mood
   - 书/文章/课程相关，有书名或作者 → reading
   - 突然冒出来的点子、选题、想做的事、一句想记住的话 → idea
   - 一段话里同时包含多类 → 拆成多条，各归各类，分别写入。
2. **保留原话**。用户怎么说的就怎么记，不要润色、不要升华、不要改成书面腔。口语就留口语。
   - 读书笔记：尽量带书名、作者、页码；摘录与自己的感想分开写。
   - 用户没给标签就不加标签，不要自作主张贴。
3. **执行写入**：

```bash
C:/Users/Administrator/.workbuddy/binaries/python/versions/3.13.12/python.exe \
  C:/Users/Administrator/.workbuddy/skills/daily-journal/scripts/record.py \
  --type mood --text "今天把课纲收尾了，心里踏实" --tags 状态
```

参数：`--type` 必填（mood|reading|idea）；`--text` 必填；`--tags` 可选，逗号分隔；`--date` 可选，默认今天，补记前几天用 `YYYY-MM-DD`；`--dir` 可选，默认 `~/.workbuddy/journal`。

脚本负责建目录、建文件、按节插入、时间戳、维护节顺序，不要手工编辑 md 去追加。

4. **回复一句话**，确认记下了 + 类型 + 文件路径。不要复述内容，不要夸「这个想法很棒」。

## 边界

- 只做追加，不修改、不删除已有条目。用户要改先确认改哪条。
- 不替用户编造没说过的心情或感想；信息不足就按原话记，不脑补。
- 不主动做周报月报、不做检索、不做灵感转选题，除非用户明确要求。
